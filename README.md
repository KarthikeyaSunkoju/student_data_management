# student_data_management
student_record_management_system
Here I developed a menu-driven Student Record Management System in C using a singly linked list, dynamic memory allocation, modular programming, searching, sorting, and file handling. This project provides an efficient way to store, manage, update, search, and organize student information using dynamically created linked-list nodes.

Features -> Add new student records -> Remove records using roll number or student name -> View all student records -> Update records using roll number, name, or percentage -> Arrange records based on name or percentage -> Reverse the linked list -> Remove all records from memory -> Store and retrieve records through student.dat -> Validate user input and manage memory properly

Concepts Used -> C Programming -> Structures and Pointers -> Singly Linked List -> Dynamic Memory Allocation -> File Handling -> Searching and Sorting
